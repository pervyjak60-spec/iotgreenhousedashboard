# IoT Smart Greenhouse

Веб-платформа управления теплицей: мониторинг датчиков, автоматика полива, вентиляции и света, тревоги, аналитика и рекомендации. Чистый HTML/CSS/JS, без сборки: откройте `index.html`.

## Страницы
index — главная · dashboard — сводка · zones — зоны · sensors — датчики (можно имитировать отказ) · control — авто/ручной режим и аварийная остановка · alerts — тревоги и журнал · analytics — графики, расход воды, рекомендации · settings — пороги автоматики

## Скрипты
- `data.js` — зоны, датчики, начальное состояние
- `storage.js` — сохранение в localStorage
- `simulator.js` — симуляция показаний каждые 2 с
- `automation.js` — правила полива, вентиляции, света
- `alerts.js` — генерация и обработка тревог
- `dashboard.js` — навигация и страницы
- `analytics.js` — графики и рекомендации

## Логика автоматики
Полив включается при влажности почвы ниже порога, вентиляция — при превышении температуры или влажности воздуха, свет — при недостатке освещения днём. Используется гистерезис, чтобы устройства не «дребезжали».
